# ML Zoomcamp 2026 - Homework 3

- `03-homework.ipynb` - solutions for Homework 3

- Python 3
- pandas

Keep `course_lead_scoring_2026.csv` in the same folder as the notebook.

Open `03-homework.ipynb` in Jupyter Notebook, JupyterLab, or VS Code and run all cells from top to bottom.

Answers are written in the comments below each question.
