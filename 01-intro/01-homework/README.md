# ML Zoomcamp 2026 - Homework 1

Homework for Module 1: Introduction to Machine Learning.

## Files

- `homework.ipynb` - solutions for Homework 1
- `car_fuel_efficiency_2026.csv` - dataset used in the notebook

## Requirements

- Python 3
- NumPy
- pandas
- Jupyter Notebook

## Running the notebook

Keep `car_fuel_efficiency_2026.csv` in the same folder as the notebook.

Open `homework.ipynb` in Jupyter Notebook, JupyterLab, or VS Code and run all cells from top to bottom.
